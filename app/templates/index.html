Key Engineering Safeguards

  • Deterministic Refusal: When semantic similarity falls below the relevance threshold, the AI explicitly reports unmentioned facts rather than guessing.
  • Source Attribution: Every retrieved chunk logs the file name, page number, and cosine relevance score.
  • Duplicate Immunity: Duplicate file uploads are caught and flagged to prevent vector store pollution.
